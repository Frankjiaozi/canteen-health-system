# 计算口径与三餐手算样例

更新：2026-10-19。样例取自当前演示库的配方与价格，仅用于核对公式，
不是真实食堂台账；价格是演示值，营养来源以食材/调味料的 `data_source`、
`source_version` 为准。

本文对应 [业务后端任务](partner-backend-data.md) 的 C01：先把每份、整餐、人数、
份数、市品、可食部和采购金额的口径写清楚，再用三餐样例逐项复算。

## 1. 统一公式

### 1.1 食材营养

食材营养按**每 100 克可食部**存储。配方用量是**每份市品克数**：

```text
某食材对单份的贡献
= 配方用量(g) / 100 × 可食部比例 × 每100g可食部营养值
```

可食部只用于营养换算。缺营养值时不能按 0 计算，结果应标记缺失并放宽误差区间。

### 1.2 调味料

调味料没有可食部折算，按配方分摊量直接计算：

```text
调味料贡献 = 每份调味料用量(g) / 100 × 每100g调味料营养值
```

油、盐、添加糖既进入单份营养，也作为餐次约束的调味料用量来源。

### 1.3 单份与人均

```text
单份菜品营养 = Σ 食材贡献 + Σ 调味料贡献
实际消耗份数 = 出餐份数 × (1 − 剩余比例)
人均营养 = Σ(单份营养 × 实际消耗份数) ÷ 就餐人次
```

“供餐营养”不是“实际摄入量”。剩余比例为 10% 时，500 份里按 450 份计算，
不能拿 500 份直接除人数。

### 1.4 采购与金额

```text
采购量(kg) = Σ(每份用量(g) × 份数) ÷ 1000
行金额(元) = 采购量(kg) × 单价(元/kg市品)
采购合计 = 各行金额按分四舍五入后的和
```

单价是**市品价**，计算金额时不再乘可食部比例。食材和调味料都按同一套规则汇总；
同名食材合并后再算金额。

### 1.5 取数与舍入

- 单份营养优先取：抽样实测 > 当日校准 > 标准配方理论值。
- 营养结果按现有字段精度展示：能量 2 位、蛋白质/脂肪/碳水 3 位、钠 2 位。
- 采购量保留 3 位小数，金额保留 2 位小数。
- 行金额先按分四舍五入，再合计；因此“精确成本 × 100”与“逐行金额求和”可能差 1 分。
- 营养公式用 Decimal 计算，不用浮点数。

## 2. 早餐样例：白粥

配方版本 1，单份 300 克，配方只有大米 60 克，无调味料。

### 2.1 食材贡献

| 食材 | 配方用量 | 可食部 | 每 100g 可食部能量 | 单份能量贡献 |
| --- | ---: | ---: | ---: | ---: |
| 大米 | 60g | 1.00 | 352.06 千卡 | 60/100 × 1.00 × 352.06 = 211.236 |

其余四项：

```text
蛋白质 = 60/100 × 1.00 × 7.400 = 4.440 g
脂肪   = 60/100 × 1.00 × 0.800 = 0.480 g
碳水   = 60/100 × 1.00 × 77.900 = 46.740 g
钠     = 60/100 × 1.00 × 3.80 = 2.280 mg
```

系统单份结果：能量 211.24 千卡、蛋白质 4.440g、脂肪 0.480g、碳水 46.740g、钠 2.280mg。

### 2.2 采购成本

```text
每份成本 = 60 / 1000 × 5.60 = 0.336 元
100 份采购量 = 6.000 公斤
100 份金额 = 6.000 × 5.60 = 33.60 元
```

## 3. 午餐样例：番茄炒蛋

配方版本 1，单份 150 克，食材为番茄 80g、鸡蛋 60g；调味料为大豆油 6g、
白砂糖 1.5g、食盐 1.2g。

### 3.1 食材贡献

| 食材 | 用量 | 可食部 | 能量 | 蛋白质 | 脂肪 | 碳水 | 钠 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 番茄 | 80g | 0.97 | 15.942 | 0.6984 | 0.1552 | 3.1040 | 3.880 |
| 鸡蛋 | 60g | 0.88 | 75.588 | 7.0224 | 4.6464 | 1.4784 | 69.432 |

### 3.2 调味料贡献

| 调味料 | 用量 | 能量 | 蛋白质 | 脂肪 | 碳水 | 钠 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 大豆油 | 6g | 53.002 | 0 | 5.994 | 0 | 0.294 |
| 白砂糖 | 1.5g | 6.087 | 0 | 0 | 1.499 | 0.006 |
| 食盐 | 1.2g | 0 | 0 | 0 | 0 | 471.732 |

### 3.3 合计

```text
能量 = 15.942 + 75.588 + 53.002 + 6.087 + 0 = 150.620 → 150.62 千卡
蛋白质 = 0.698 + 7.022 + 0 = 7.720 → 7.721 g
脂肪 = 0.155 + 4.646 + 5.994 = 10.795 → 10.796 g
碳水 = 3.104 + 1.478 + 1.499 = 6.081 g
钠 = 3.880 + 69.432 + 0.294 + 0.006 + 471.732 = 545.344 → 545.34 mg
```

系统单份结果与本表一致：150.62 千卡、7.721g、10.796g、6.081g、545.34mg。

### 3.4 成本

```text
番茄 80/1000 × 4.50 = 0.360
鸡蛋 60/1000 × 9.60 = 0.576
大豆油 6/1000 × 12.00 = 0.072
白砂糖 1.5/1000 × 6.00 = 0.009
食盐 1.2/1000 × 2.50 = 0.003
合计 = 1.020 元/份
100 份金额 = 102.00 元
```

注意：番茄的可食部 0.97 只影响营养，不影响 0.360 元的采购成本。

## 4. 晚餐样例：土豆炖牛肉

配方版本 1，单份 180 克，食材为马铃薯 80g、牛肉（瘦）70g、洋葱 20g、胡萝卜 15g；
调味料为生抽 4g、大豆油 4g、玉米淀粉 1.5g、食盐 1.5g。

### 4.1 单份营养

| 来源 | 能量 | 蛋白质 | 脂肪 | 碳水 | 钠 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 马铃薯 | 58.949 | 1.504 | 0.150 | 12.934 | 2.030 |
| 牛肉（瘦） | 75.117 | 14.140 | 1.610 | 0.840 | 37.520 |
| 洋葱 | 7.357 | 0.198 | 0.036 | 1.620 | 0.792 |
| 胡萝卜 | 5.645 | 0.144 | 0.029 | 1.267 | 10.282 |
| 生抽 | 2.572 | 0.224 | 0.004 | 0.404 | 230.280 |
| 大豆油 | 35.335 | 0 | 3.996 | 0 | 0.196 |
| 玉米淀粉 | 5.263 | 0.018 | 0.002 | 1.275 | 0.095 |
| 食盐 | 0 | 0 | 0 | 0 | 589.665 |
| **合计** | **190.237** | **16.228** | **5.827** | **18.341** | **870.860** |

系统单份结果：190.24 千卡、16.228g、5.827g、18.341g、870.86mg。

### 4.2 成本

```text
马铃薯 8.0kg × 3.00 = 24.00
牛肉   7.0kg × 62.00 = 434.00
洋葱   2.0kg × 3.40 = 6.80
胡萝卜 1.5kg × 3.20 = 4.80
生抽   0.4kg × 8.00 = 3.20
大豆油 0.4kg × 12.00 = 4.80
玉米淀粉 0.15kg × 7.00 = 1.05
食盐   0.15kg × 2.50 = 0.375 → 0.38（按分四舍五入）
合计 = 479.03 元 / 100 份
```

精确成本是 479.025 元；采购单按行金额舍入后是 479.03 元。这个 1 分钱差异要保留说明，
不能一边展示 479.025、一边声称与行项目合计完全一致。

## 5. 人均换算样例

以番茄炒蛋为例：

```text
100 份出餐、120 人就餐、无剩余：
人均能量 = 150.62 × 100 / 120 = 125.52 千卡

100 份出餐、120 人就餐、剩余比例 10%：
实际消耗 = 100 × (1 − 0.10) = 90 份
人均能量 = 150.62 × 90 / 120 = 112.97 千卡
```

这两个结果不能与“整餐投料总量”混读。油盐糖的实际投料总量还要以采集单为准。

## 6. 与接口对照

- 单份营养：`GET /api/v1/dishes/{dish_id}` 的 `nutrition`。
- 食材来源与可食部：`GET /api/v1/ingredients` 的 `data_source`、`source_version`、`edible_ratio`。
- 调味料来源：`GET /api/v1/seasonings`。
- 份数、采购与人数：`POST /api/v1/menu-plan/generate` 或 `generate-day`。
- 理论/校准/抽样：`GET /api/v1/calibration/comparison`。

样例日期固定为 `2026-10-20`，配方版本见对应菜品响应。配方或价格变化后，
这些样例需要重新生成，不能拿旧数字冒充当前结果。
