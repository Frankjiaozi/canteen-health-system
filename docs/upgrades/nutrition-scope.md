# 营养目标的适用范围与当前限制

2026-10-16 核对了国家卫生健康委员会的 [WS/T 554—2017《学生餐营养指南》发布页](https://www.nhc.gov.cn/wjw/yingyang/201708/e8a131882d2c4a8c95f10a8b7b5fe662.shtml) 与其 [官方标准文件](https://www.nhc.gov.cn/ewebeditor/uploadfile/2018/06/20180613135619237.pdf)。该指南的适用对象为 6–17 岁中小学生。项目服务大学食堂，当前实现不能据此自动认证大学生一餐或全天营养合规。

本轮没有擅自重定一套大学生营养数值，也没有把既有功能验证阈值改称权威标准。`recommendation/targets.py` 保留求解器已有数值，补充适用范围和来源链接，并删除“单餐不超全天上限即可保证全天合规”的错误推断。单餐、全天、个人需求和群体平均是不同口径，页面和报告必须保留这一限制。

能量、蛋白质等软目标可能有差距；系统应展示实际值与差距，不能因为求解成功就称全部达标。油盐糖等硬约束只表示当前模型中的计算边界，不能替代实际采集、个人健康判断或营养师确认。份数缩放、配方市品重量、营养来源、未核实日历和缺价等假设仍需一并说明。

协作者后续若调整数值，应先明确目标人群、餐次分配、资料版本、原文依据与单位，再更新计算规则版本和回归。数据体检仅检查结构/缺项，不能代替来源核实；本机示例为合成数据，不应宣传实际降低浪费或改善健康的效果。
